Sibling raw event-log directories are excluded from the archive and remain under ignored target; each generated event-log summary is included. The generated JAR is not included in Git: its actual SHA and packaging/class/source checks bind the retained local artifact and replay recipe.
- `runtime/`, `probes/`: resolved cached artifacts, actual class/source hashes, local and separate-executor reports. Null version metadata remains null. Same-machine evidence cannot establish multi-host sharing or EMR compatibility.
- `build/build-engineer-report.md`, `build/fullcheck-attempt2-summary.json`: final gate and packaging result. `build/commands-tests-and-attempts.tar.gz` retains372 public build scratch files: exact commands/logs/runners, failed attempts, primary-source/POM proof, source freezes, finalizer erratum and XML. `build/archive-inventory.json` binds every member; its source manifest v2 checked370 entries before archival. The two manifest versions themselves explain the larger archive count. This is evidence preservation, not executing those runners during review.
- `baseline.json`, `preservation-before.json`, `preservation-after.json`, `append-only-records.json`, `record-suffixes/`: original tracked blobs and exact five old/new record boundaries; human decision unchanged. The frozen budget packet remains untouched.
- `candidate-manifest.json`: final public candidate byte inventory, excluding only itself to avoid a self-hash cycle. No actual-recipient private scan was run or implied for this offline candidate.
