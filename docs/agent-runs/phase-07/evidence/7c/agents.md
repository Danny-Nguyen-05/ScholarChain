# Native ownership — Subphase 7C

Native continuations inherit the parent model; no overrides, nested delegation or reviewer.

| Native ID | Role | Exclusive writing territory | Work order |
|---|---|---|---|
| /root | Coordinator | docs/agent-runs/phase-07/** | Commit gate, questions/accepted defaults, evidence, serialized owner-requested commands and handoff |
| /root/test_engineer | test-engineer | tests/** | Independent hardening, N6 SDK stubs, runtime graph capability fence and regressions |
| /root/storage_engineer | storage-engineer | modules/storage/** | Tagged live suite authored/compiled only, README completion and necessary scoped repairs |

Build owner is invoked only for an evidenced compilation dependency. Runtime modules currently have no application code; no runtime implementation or Phase8 work is authorized. Coordinator may execute owner-requested formatting/tests while source ownership stays with each owner.
