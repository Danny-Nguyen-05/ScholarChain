description: Route ScholarChain failure diagnosis to incident-responder
---

Use the `incident-responder` agent for the incident described by `$ARGUMENTS`. Start with read-only evidence: incident ID, time range, detection source, user impact, run and trace IDs. Ask the owner of any defective implementation for a repair through the orchestrator. Require a human gate before live recovery, security changes, destructive action or rollback. Preserve timeline, root cause, data-integrity assessment and a preventive test.
