The new `post-freeze-scan` additionally requires `--verification-receipt-sha256`, the externally checked canonical hash of its new verification receipt, derived from captured PUBLIC stdout as described below. ## Derive the scan pin from captured PUBLIC stdout

The verifier's stdout is a one-line public JSON object. Its private receipt file uses UTF-8 with sorted keys, indent2, Python's default ensure_ascii=True and one actual trailing LF byte. Hashing the original stdout bytes is WRONG. The pure `canonical_receipt_bytes` function matches the core `save_json` writer exactly; the tested recipe below shows the unambiguous encoding.

After a successful future authorized `verify`, capture its PUBLIC stdout alone in a public local file outside Git (for example `/tmp/scholarchain-verify-public-stdout.json`). It must contain exactly that one successful JSON receipt, not shell prompts or errors. This recipe reads only that public file, never the private operation receipt:

```sh
python3 -I - <<'PY_RECIPE'
from pathlib import Path
import json, hashlib
public_path = Path("/tmp/scholarchain-verify-public-stdout.json")
receipt = json.loads(public_path.read_text(encoding="utf-8"))
assert receipt.get("stage") == "verify" and receipt.get("option") == "B"
canonical = (json.dumps(receipt, sort_keys=True, indent=2) + "\n").encode("utf-8")
print("Verification receipt SHA256:", hashlib.sha256(canonical).hexdigest())
PY_RECIPE
```

The human must check this public capture's exact new gate/operation/plan/actor and successful result, then use that hash as `--verification-receipt-sha256`. The synthetic regression round-trips actual public stdout through the same recipe and proves byte/hash equality to the synthetic private receipt file; it also proves raw stdout's hash differs. The runtime's private checkpoint and same-gate checks authenticate linkage locally, while external human/source provenance remains necessary. This is not a recipient hash and adds no output field or production mode. No actual private receipt is read just to obtain this pin.
